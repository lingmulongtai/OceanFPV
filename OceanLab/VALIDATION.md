# 検証記録

2026-10-12、Godot **4.6.3.stable.official.7d41c59c4**、Linux。

GPU処理と画面描画は **Vulkan 1.4.305 / Forward+ / Mesa llvmpipe** で実行しました。ハードウェアGPUではなくCPUのソフトウェアVulkanです。以下は実際のGPU経路の検証結果であり、簡易波の結果ではありません。ハードウェアGPUでのFPSやドライバー互換性の保証には使えません。

| 検証 | 結果 |
| --- | --- |
| Godotプロジェクト起動・GDScript | 成功 |
| 27点の静水圧による浮力、平らな水面での8秒の収束 | PASS、船体原点の最終Y=0.02577 m（許容±0.15 m） |
| 一時停止時の船の位置固定 | PASS |
| 3つの海況、座標を変えたCPU簡易波の有限値 | PASS |
| Vulkanでの5段×128²のFFT | PASS |
| Vulkanでの5段×512²のFFT | PASS |
| 全5段の全画素の変位、NaN/InfとDC成分 | PASS |
| 既知の1つのFourierモードに対するFFTの実出力 | PASS、4つの座標でsin/cosとの誤差<0.0001 |
| GPU→CPUの27点の非同期波高 | PASS、30フレームの検証で15回コールバック |
| 追従クリップを1 texel動かした時、泡がワールド座標に残る | PASS、RGBA16Fの誤差許容0.002 |
| OpenGLの簡易表示への切替・全描画用シェーダー | PASS、ANALYTIC PREVIEWを表示 |

512²で測定した、増幅前のカスケードごとの高さ標準偏差（m）：

| タイル長 | 平均高さ | 標準偏差 |
| --- | --- | --- |
| 2003 m | 0.00000056 | 0.74024 |
| 433 m | −0.00000045 | 0.99964 |
| 97 m | −0.00000054 | 0.27685 |
| 23.3 m | 0.00000001 | 0.06163 |
| 5.3 m | −0.00000002 | 0.01369 |

既定の2.8倍は迫力を優先した設定です。周波数帯は別々ですが、ここで測った有限タイルの標準偏差を単純合成した値は、実際のシーンの有義波高を測定した値ではありません。

現時点では、元動画と同等の写実性に到達したとは評価していません。実写36枚に対する8項目の独立採点、HDRIの太陽の実測、実艦の塗装校正、ASSOC.の菊月モデルの導入は未実施です。影・空・船体と泡の見た目には、引き続き調整の余地があります。

再実行するコマンドと原投稿との差は [README.md](README.md) に記載しています。
