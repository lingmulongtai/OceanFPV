Its FPS is not a hardware-GPU benchmark. The later native-GPU checks are described separately above. Performance depends on the GPU, browser, resolution and quality. HIGH/ULTRA support up to 4×MSAA for fine rigging/edges; BALANCED reduces reflection resolution and disables shadows/bloom/MSAA.

## Reproduction

```sh
npm ci
npm test
npm run build
npx playwright install chromium
npm run test:browser
node scripts/verify-deployment.mjs https://lingmulongtai.github.io/OceanFPV/
node scripts/verify-deployment.mjs https://lingmulongtai.github.io/OceanFPV/ --quality=ultra --visual-only
```

The publication check uses BALANCED for controls, real pointer lock/mouse movement and photo/model delivery. The separate ULTRA command checks the actual 2× drawing buffer and captures its daylight render without using the development hook. Both write screenshots to ignored `artifacts/`. GitHub Actions retains browser traces/screenshots and deploys only after verification passes.

Windows can additionally run the same browser suite on native Direct3D11 with PowerShell `$env:OCEANFPV_NATIVE_GPU='1'; npm run test:browser`. The scene case reports the actual renderer and rejects software fallback. Remove that environment variable afterward to return to the default harness. Add `--native-gpu` to the deployment command for the same verified backend; it fails if native Direct3D11 is unavailable. This optional mode does not change GitHub Actions or the default software-GPU test configuration.
