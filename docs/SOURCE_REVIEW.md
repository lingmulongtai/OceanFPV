# OceanLab review and reuse

Reviewed 2026-10-12 before the browser implementation. The supplied ZIP is preserved locally; its complete contents are extracted to `OceanLab/` and tracked as the original reference. Existing preview images and validation claims describe the **Godot** build, not OceanFPV browser validation.

The original is a procedural 92 m destroyer, not a submarine or a third-party photogrammetry model. Its 33 hull sections, `4.4 * sin(πu)^0.42` half-width, bow sheer, bridge, twin funnels, radar, railing and rigging inform `src/world.ts`. The browser model adds separate window panes, beveled structures, material detail, deck fittings, ladders and a helipad. The original self-generated ocean ambience is reused in `public/ocean_ambience.wav`.

`GPUOcean.start()` rejects Compatibility rendering. The five-cascade FFT uses Godot RenderingDevice/Vulkan compute, storage buffers and asynchronous readback. These operations do not survive a Godot WebGL2 export. Therefore this project uses Three.js/WebGL2 rather than claiming the original FFT works in a browser.

The first browser version used the original `CPUSea.rebuild()` analytic fallback. After visual review, the live renderer is replaced by a browser-native **three-cascade FFT** in `src/spectrum.ts`: Gaussian Phillips wind spectra, Hermitian time evolution, normalized row/column IFFT, horizontal chop, displaced tangents and Jacobian foam. It is informed by the original MIT spectral shaders but does not execute Godot's Vulkan compute. The CPU field is uploaded to WebGL textures and queried with inverse horizontal displacement for collision and buoyancy. `src/sea.ts` retains the original analytic reference and sea preset scales. Radial mesh spacing is inspired by `OceanMesh`.

Water optics are adapted from `ocean.gdshader`: absorption/backscatter-inspired blue-green body color, Fresnel, roughness and atmospheric distance haze. Daylight uses a licensed self-hosted photographic HDR sky; evening uses Three.js's atmospheric Sky. Reflections use the same sky. Original physical buoyancy and GPU particle spray are not executed by the browser port. Ship bobbing samples browser waves and the vessels follow new continuous routes. Collision uses conservative gameplay volumes. This is not CFD or a validated real-world training simulator.

All original OceanLab additions and the ambience are MIT. `OceanLab/LICENSE` is retained. The original spectral code includes Ethan Truong's GodotOceanWaves MIT license at `OceanLab/third_party/GodotOceanWaves-LICENSE`; the Godot compute shaders remain separate reference files. The browser runs its own normalized CPU FFT. See `THIRD_PARTY.md` for runtime attribution.
