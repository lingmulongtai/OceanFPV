# OceanFPV

海と船の上を自由に飛ぶ、ブラウザだけで動くFPVドローンゲーム。

**[ゲームを開く](https://lingmulongtai.github.io/OceanFPV/)** · [入力と検証](docs/VALIDATION.md) · [元ZIPのレビュー](docs/SOURCE_REVIEW.md)

## 遊び方

インストール不要。WebGL2が使えるデスクトップブラウザで開き、「自由飛行」または「タイムトライアル」を選び、海へ飛び立ちます。初めてならANGLEで、Spaceを押して航行中の駆逐艦のヘリパッドから少し上昇してください。Rのリセットも現在の船の位置に追従します。

| 操作 | キーボード | Xbox標準ゲームパッド |
| --- | --- | --- |
| 前後・左右へ傾く | W/S・A/D | 右スティック |
| 上昇・下降 | Space・Shift | 左スティック上下 |
| 左右へ旋回 | Q/E | 左スティック左右 |
| アーム・解除 | F | A |
| 離陸地点へ戻る | R | X |
| FPV・追従カメラ | C | Y |
| 一時停止 | Esc | Menu |
| 設定 | Tab / 歯車 | 歯車をクリック |
| ミュート・HUD | M・H | キーボード併用 |

ANGLEは傾きと垂直速度を補助します。慣性があるので、止まるには逆方向へ傾けます。ACROは回転速度を操作し、姿勢・高度を自動で戻しません。海面・船・島に接触すると終了し、リセットで再挑戦できます。自由飛行の範囲は原点から約1.9 km、高度500 mです。

タイムトライアルは緑のゲートを番号順に通過する6ゲート×3周。ゲートは進行方向へ抜ける必要があります。毎回同じ船の位置・海面の時刻から開始します。最速タイムと設定は、このブラウザのローカルストレージに保存します。途中の衝突・リセットでは全周をやり直します。ランキングサーバーやアカウントはありません。

## Xbox・FPV送信機

XboxをUSB/Bluetoothで接続し、ボタンを押してから設定の「コントローラー」でXboxを選びます。標準Gamepad mappingの左スティックはヨー/上昇下降、右はロール/ピッチです。スプリング式スロットルはANGLEで中立時の垂直速度を0へ補助します。

FPV送信機はOSにUSB Joystick/HIDゲームコントローラーとして認識されるモードで接続します。「FPV送信機」でデバイスを選択し、ロール/ピッチ/ヨー/スロットルの4軸を重複なく割り当てます。全スティックを中央（スロットルも中央）にして校正開始 → 全軸を端まで動かす → 保存。必要に応じて軸を反転し、モニターを確認します。送信機のスロットルは0〜100%の直接操作です。

送信機はスロットルが12%以下でアーム/再開できます。初期割り当てはAxis 0/1/2/3で、スロットルは反転しています。機種ごとに割り当てと校正が必要です。デバイス接続切れ・別デバイスへの切替・非アクティブタブでは一時停止します。接続を確認して再開してください。

ブラウザにゲームパッドとして公開されないUSB機器を、このページから直接接続することはできません。特定のFPV送信機の動作やXbox実機の合格を、仮想Gamepad APIテストだけから保証していません。[MDNのGamepad API説明](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API)。

マウス操作は設定で有効にして飛行画面をクリック。マウス位置はロール/ピッチの仮想スティックとなり、Q/E、Space/Shiftを併用します。Escでロックを解除/一時停止します。タッチ操作は実装していません。スマートフォンでは接続コントローラーが必要です。

## 画質

- 航行する260 m客船：8層の客室デッキ、独立したバルコニー、ガラス、救命艇18艇、プール、チーク甲板、船橋、アンテナ、舷窓。92 m駆逐艦と28 mヨットも別の連続した航路を進みます。船首・船尾まで閉じた128分割船体です。
- 海：独立した433/97/23.3 mの3つのFFT波面。Gaussian位相の風波スペクトル、横方向の波頭変位、Jacobianの白波、航行方向に追従する航跡・船首泡、Fresnel、GGX反射、波頭の透過色、浅瀬と海岸の泡。衝突と船の浮き方はGPUに送る波面データを共有し、横変位も逆算して海面を調べます。
- 空：晴天では自前配信のCC0 4K HDR写真を空と環境光に使用し、太陽方向も画像から求めます。夕景・残照は大気散乱とプロシージャル雲です。船・島・空を水面に反射します。
- 陸地：192×192区画の不規則な地形、写真由来の岩肌PBR、CC0の樹木スキャン、海岸の岩、灯台。西島の岬には約94万三角形の写真測量の崖を実寸で配置し、地面・接触・専用の水深を接続しています。近い樹木は枝葉の3Dモデル、遠い森林は同じモデルから生成した8方向の描画画像を使います。木・岩にも接触判定があります。[崖の出典・検証と近似](docs/COASTAL_CLIFF.md)。
- HIGH：最大1.5×端末ピクセル比、1536²反射、最大4×MSAA、4096²影、任意のブルーム。ULTRA：端末比によらず縦横2×スーパーサンプリング、3072²反射、約37万海面三角形。BALANCED：1×、512²反射、影/ブルーム/MSAAなし。
- 音：元OceanLabの自作波音と、モーター出力に連動する合成ローター音。

高画質はGPU性能が必要です。FPSを右上に表示し、負荷が高ければBALANCEDへ変更できます。初回は樹木・岩・写真素材・HDRを含む約208 MBを読み込みます（コード・音声を除く）。取得に失敗した素材は標準素材へ戻り、ゲームを開始できます。船はコードで生成したモデルです。海はFFTですが、CFD、Unreal Engine、実機の飛行特性を校正した訓練用シミュレーターではありません。[描画事例の調査](docs/OCEAN_RESEARCH.md)。

## 開発

Node.js 22.12以上。

```sh
npm ci
npm run dev
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

`dist/`が静的配布物です。APIキーやCDNからの実行時モデル/テクスチャ取得はありません。ローカルもHTTPサーバー経由で開いてください。`file://`で直接開く方式には対応しません。

| ファイル | 役割 |
| --- | --- |
| `src/flight.ts` | 120 Hz固定刻み、重力、機体姿勢、推力、空気抵抗、ANGLE/ACRO |
| `src/input.ts` | キー、マウス、Gamepad API、軸反転・校正・デッドゾーン |
| `src/spectrum.ts`, `src/ocean.ts` | CPU FFT・接触サンプリング、GPU描画、反射・航跡 |
| `src/world.ts`, `src/cruise.ts`, `src/hull.ts` | 船、島、灯台、ヨット、衝突、レースゲート |
| `src/navigation.ts`, `src/terrain.ts` | 船の連続航路、描画と衝突が共有する地形 |
| `src/surfaces.ts`, `src/sky.ts` | ローカルPBR/HDR素材の読み込みとフォールバック |
| `src/main.ts` | ゲーム状態、UI、描画、レース、設定と記録 |
| `OceanLab/` | 元ZIPをそのまま展開したGodot参考プロジェクト |

GitHub ActionsはPRでテスト/ビルド/Chromium操作検証を実行し、mainの検証成功後にGitHub Pagesへ配信します。
