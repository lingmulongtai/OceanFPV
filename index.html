PILOT BRIEFING

フライトガイド

初めてならANGLE・キーボードで自由飛行へ。豪華客船の船首でDECK READYの間は船に追従して待機します。Space、Xboxの左スティック上、送信機のスロットル上昇で離陸。船は島の間をまっすぐ航行します。スティックを戻すと傾きが戻り、高度を補助します。慣性があるので、止まるには逆方向へ傾けます。Rで出航地点からやり直せます。

W / S前 / 後へ傾く
A / D左 / 右へ傾く
Q / E左 / 右へ旋回
Space / Shift上昇 / 下降
Fアーム / 解除
R離陸地点へリセット
C一人称 / 追従カメラ
Esc / Tab一時停止 / 設定
M / Hミュート / HUD表示

タイムトライアル：明るい緑のゲートを番号順に、数字がある側へ抜けます。6ゲート×3周でゴール。最速記録をこのブラウザに保存します。途中で衝突したら全周をやり直します。

ACRO：スティックは姿勢ではなく回転速度を操作します。高度補助はありません。キーボード・Xboxの中立スロットルは水平ホバー付近、送信機は0〜100%の直接操作です。

Xbox：接続後にボタンを押し、設定のコントローラータブで「Xbox」を選択。送信機は「FPV送信機」を選び、軸を割り当てて校正します。
